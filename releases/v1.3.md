KeyFit 1.3 keeps its setup window open while you grant Accessibility access. Click **Open Accessibility Settings**, enable the installed app, then return to KeyFit and click **Retry**. The three shortcuts activate in the same process. If permission is already enabled, KeyFit skips the setup window.

### Install on macOS 12 or later

1. Download and extract **Source code (zip)** below.
2. With the Xcode Command Line Tools installed, open Terminal in the extracted directory and run `make`. This builds a universal app for Apple silicon and Intel.
3. Move `KeyFit.app` to Applications, quit any older running copy, and open the new one. Follow the setup window if prompted.

This release contains source code only. Locally built apps use an ad-hoc signature and may need fresh Accessibility approval after an update.
